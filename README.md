# LUNAR LEGACY
### An Interactive Archive of Humanity's Footprints on the Moon

LUNAR LEGACY is an independent educational website about human-made objects left on the Moon by robotic and crewed missions. It explains what selected artifacts were designed to do, which missions deployed them, and whether they remain on the lunar surface or were retrieved.

## Features
- Searchable artifact archive with mission and disposition filters
- Artifact detail panels with source links
- Interactive schematic landing-site selector
- Short mission timeline
- Mobile-responsive layout
- Research and transparency section

## Run locally
This is a static website. Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the deployment to finish. The website should be available at:
   `https://eldhoyy.github.io/lunar-legacy/`

## Project structure
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — archive data, search, filters, artifact details, and site selector

## Data accuracy
The artifact entries are curated educational summaries, not a complete inventory. Some descriptions are intentionally qualified where status or exact location requires mission-specific verification. Coordinates in the landing-site explorer are approximate, and the map is schematic—not a navigation tool. Check each linked primary source before reusing a factual claim.
